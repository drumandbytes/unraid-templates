# unraid-templates

[More Drumandbytes projects](https://drumandbytes.com/projects/)

Unraid Community Applications templates for the [Drumandbytes](https://github.com/drumandbytes) container images.

| App | What it is |
| --- | --- |
| [momentarr](https://github.com/drumandbytes/momentarr) | Caching, serialising proxy in front of Byparr/FlareSolverr for Prowlarr |
| [pve-metrics-exporter](https://github.com/drumandbytes/pve-metrics-exporter) | Proxmox VE exporter for Prometheus and Glance, with hardware temperatures |
| [paddock-api](https://github.com/drumandbytes/paddock-api) | F1 data API for Glance dashboards |
| [github-actions-runner-exporter](https://github.com/drumandbytes/github-actions-runner-exporter) | Prometheus exporter for self-hosted GitHub Actions runners |
| [nordvpn](https://github.com/drumandbytes/nordvpn) | The official NordVPN client, distroless, as a VPN network for other containers |

Search for them in the Unraid **Apps** tab (once the repository is listed; `ca_profile.xml` is its Community Apps profile). Icons are generated from the SVGs in [`icons/`](icons). Before they're listed there, you can add a template by URL:
Docker → Add Container → Template → paste the raw URL of a file in [`templates/`](templates).

Problems with an app itself go to that app's repo; problems with a template go here.
